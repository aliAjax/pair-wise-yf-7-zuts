# 活字试印版本台

在活字排版工坊基础上改造的试印版本台：草稿阶段选定**纸张、墨色、压力**后可开试印，试印版面冻结，通过后标记采用形成只读版本；继续编辑须另存为草稿。纯前端、零依赖、本地存储，刷新后状态保留。

## 工作流

1. **草稿**：维护字模库、落字/拖拽/移动活字、调整纸张、墨色、压力、方向、网格、作品名。
2. **开试印**：以下任一情况整次拒绝，版面完全不变：
   - 压力低于 2 或高于 8；
   - 落字少于 3 处；
   - 已有未结（试印中）版本；
   - 字模超量（用量超过库存，或用到了已删除的字模）。
3. **试印中**：设置与版面冻结；任何增删、移动或换字都会**作废本次试印**，但冻结快照（纸张、墨色、压力、版面、时间、作废原因）保留在版本记录中。也可手动作废。
4. **标记采用**：试印通过后采用，版本永久只读；「另存为草稿」后才能继续编辑，版本记录不动。
5. **版本记录**：与字模库同步的缺字提示（字模事后被删或超量会标红）；作废快照和采用版本都可「另存为草稿」继续。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `index.html` / `styles.css` | 页面结构与样式 |
| `storage.js` | 本地存储（localStorage）读写、旧数据合并 |
| `rules.js` | 纸张/墨色元数据、用量与缺字汇总、试印校验规则 |
| `versions.js` | 版本状态机：试印 → 作废/采用 → 另存草稿 |
| `app.js` | 界面渲染与交互编排 |

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
