# 活字排版工坊 · 试印版本台

一个纯前端本地应用：维护字模库、在网格版面落字，并以「试印」流程把版面固化为可追踪的版本。

## 试印流程

1. 草稿阶段选好**纸张、墨色、压力**（压力 1–10），在版面落字。
2. 点击**开试印**：整单校验，任一不满足即整次拒绝、版面不变——
   - 压力低于 2 或高于 8；
   - 落字少于 3 处；
   - 已有未结试印；
   - 字模用量超量（缺字提示与校验同源，实时同步）。
3. **试印中**对版面的增字、删字、移动、换字（含清空、删字模、载入草稿/版本）会立即作废本次试印，冻结快照保留在版本记录中。
4. 点击**试印通过**生成 passed 版本；可再**标记采用**，采用版本只读。
5. 想继续编辑：在版本记录中**另存草稿**（采用版本只能另存草稿），或对未采用版本**载入续排**。

## 文件划分

- `print-rules.js` — 试印规则：压力/落字/未结单/超量校验、缺字统计、墨色与版本状态常量。
- `version-store.js` — 版本状态：开印、通过、作废、采用、另存草稿。
- `storage.js` — 本地存储：localStorage 读写、默认状态与缺省合并，刷新后保留。
- `app.js` — 界面渲染与交互接线。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。无外部依赖。
